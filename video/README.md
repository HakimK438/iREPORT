# iREPORT video

Remotion project for the iREPORT LinkedIn video. Separate from the app in the repo root.

## Preview
    npm run studio            # opens http://localhost:3000 -> "Intro"

## Render
    npx remotion render src/index.ts Intro out/ireport-intro.mp4

## Change timing or sound
- All cue frames live in `src/timeline.json` (30 fps, 120 BPM: 1 beat = 15 frames).
- Music and most sound effects are generated by `python scripts/make_intro_audio.py`
  (numpy + scipy). Re-run it after changing the timeline or the sound design.
- Volumes and placement of each sound: `src/intro/IntroAudio.tsx`.
- `public/sfx/mouse-click.wav` is from remotion.media; everything else in `public/audio` and `public/sfx` is synthesised.

## Assets
- Skyline: `the app's Location_images (kept outside the repo)/andheri_west.png` (resized). Confirm its licence before posting publicly.
- Icons: copied from the app (`src/components/Icon.tsx`). Colours and fonts: the app's `index.css`.

## LinkedIn video (46 s, composition "LinkedIn")
    npx remotion render src/index.ts LinkedIn out/ireport-linkedin.mp4
- Shots, captions, cursor moves and clicks: `src/full/shots.ts`. Sections: `src/full/timeline.json`.
- Music: `python scripts/make_full_audio.py` (run with `PYTHONPATH=scripts`).
- Screens are real captures of the running site: `node capture/citizen.mjs`, `node capture/officer.mjs <ID>`,
  `node capture/confirm.mjs`, `node capture/extras.mjs` (needs the API on :8000 and the site on :8443).
  `citizen.mjs` files a real report, so re-running it creates a new one.
